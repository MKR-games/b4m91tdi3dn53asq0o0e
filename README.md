# 《똑... 똑... 똑...》 모바일 엔딩 북

## 실행 방법

1. ZIP 파일의 압축을 해제합니다.
2. `index.html`을 Chrome, Edge, Firefox 또는 Safari에서 엽니다.
3. 별도 설치나 인터넷 연결 없이 사용할 수 있습니다.

## 파일 구성

- `index.html`: 실행 파일
- `style.css`: 화면 디자인
- `script.js`: 투표 결과 선택, 스포일러 단계, 글자 크기와 상태 기억 기능
- `PretendardVariable.woff2`: 오프라인용 Pretendard 글꼴
- `Pretendard_LICENSE.txt`: 글꼴 라이선스

이 엔딩 북은 게임의 최종 투표가 끝난 뒤에만 열어야 합니다.

## 반영 기준

- 최종 MAP 동선 기준
- 22:31~22:36 마지막 반복 노크 구간
- 한유정의 재감금·생존 신호 외면·증거 은폐를 최종 책임 판정 기준으로 반영
